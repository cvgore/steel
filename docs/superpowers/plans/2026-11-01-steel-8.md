# STEEL-8 — plan implementacji

Status: użytkownik zatwierdził pełny zakres STEEL-8 (2026-11-01); implementacja całości i weryfikacja zakończone. Proces: aktualny implement-task, weryfikacja proporcjonalna do ryzyka.
Źródło wymagań: https://vikunja.gigakoks.fans/jira/browse/STEEL-8 i nadrzędny STEEL-3, odczytane 2026-11-01. Archiwalny STEEL-15 nie definiuje zakresu.

**Cel:** atomowy zapis wspólnego treningu przez istniejący graf Core Data telefonu oraz trwała, mała replika Watch.

**Architektura:** telefon zachowuje istniejące obiekty i UUID. Jedna granica operacji zapisuje wynik, kolejność, wersję, odpoczynek i dyspozycję operacji w jednym zapisie persistent store. Watch przechowuje snapshot i uporządkowane lokalne operacje; nie przenosimy całego WorkoutDataKit na zegarek.

**Technologie:** Swift, Core Data, Codable, XCTest, SwiftUI. Ustawienia targetów i wersje zależności pozostają poza zakresem zmian.
